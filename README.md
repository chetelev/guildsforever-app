# Guilds Forever app

Installers and update files for the Guilds Forever app for Windows, from [guildsforever.com](https://guildsforever.com).

The app is free. It shows guildsforever.com in a window of its own and keeps the Guilds Forever addon and your profile in step, by reading and writing only the files the game sets aside for addons. It never touches the game itself.

There are no public releases yet: the first versions go to a few testers, and public releases follow once the app is signed. Installed copies update themselves from this repository's Releases.

The app's source code isn't published here; this repository only holds what it installs and updates from.

Questions or problems: use Feedback & support on [guildsforever.com](https://guildsforever.com).
